# Python分野の地図

## これは何か

Python本体、実行環境、ライブラリ、開発ツールを安全に使い分けるための知識をまとめる分野です。
コードの書き方だけでなく、環境構築、依存関係、再現性、Jupyterなどの周辺運用も扱います。

## この分野で扱うこと

- Python本体とライブラリの関係
- conda、Miniconda、Anaconda、pip、venvの使い分け
- プロジェクトごとの環境分離
- `environment.yml`などを使った環境の再現
- Jupyterやデータ分析ライブラリの導入
