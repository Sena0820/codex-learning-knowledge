# ChatGPTとCodexの利用制限の参照メモ

## まず結論

ChatGPT Plusでの `チャット` と `Codex` の利用制限、リセット周期、creditsの扱いを確認するための参照メモです。

## 用途

- 現在のChatGPTとCodexの利用条件を確認する。
- 期間限定施策やcredits追加可否を確認する。
- チャット側に共通ダッシュボードがあるかどうかを確認する。

## 参照先

- [ChatGPT pricing](https://chatgpt.com/pricing/)
  - Plusの `limits apply` 表記を確認する。
- [ChatGPT usage limits](https://help.openai.com/en/articles/6825453-chatgpt-usage-limits)
  - 機能別上限、バナー、リセット表示の扱いを確認する。
- [Using Codex with your ChatGPT plan](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)
  - 現在のCodex利用条件と usage dashboard の扱いを確認する。
- [ChatGPTプランでCodexを使う](https://help.openai.com/ja-jp/articles/11369540-using-codex-with-your-chatgpt-plan)
  - 日本語の公式案内を確認する。
- [Codex pricing](https://learn.chatgpt.com/docs/pricing)
  - `5-hour window` と `weekly limits` の説明を確認する。
- [Using Credits for Flexible Usage in ChatGPT](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-freegopluspro-sora)
  - creditsによる追加利用を確認する。
