# この分野の地図

## これは何か

Snowflake の性能、実行計画、warehouse の見方に加えて、AIでSnowflake SQLを安定生成するための考え方をまとめる分野です。

## この分野で扱うこと

- クエリ性能の見方
- 実行計画やスピルの読み方
- warehouse や micro-partition の理解
- AIでSnowflake SQLを生成するときの情報設計
- `基盤を理解する力` の中でも、実務で使うDWH知識

## この分野で見る順番

1. まずこのページで全体像をつかむ。
2. 次に [10_分野まとめ](./10_分野まとめ.md) の `全体像` と `よくある疑問` を読む。
3. 論点をまとめて戻したいときは [15_話題まとめ](./15_話題まとめ/Snowflakeの復習サマリー.md) を読む。
4. それでも気になる疑問だけ、`20_トピック/` を開く。
